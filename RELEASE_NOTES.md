## ✨ What's Inside the Desktop App

1. **📬 Outlook-Style 3-Pane Interface**:
   - **Left Folder Navigation**: Agent identities (`hello@apocalypto.in`, `researcher@...`, `coder@...`), Views (Inbox, OTP codes, Action links, Task Protocol).
   - **Middle Stream**: Search bar, instant filters (All, Unread, OTPs), real-time incoming mail stream.
   - **Right Reading Pane & Composer**: Rich email viewer, OTP 1-click copy badge, action link security verification, inline reply box, and full composer.

2. **🤖 1-Click "Connect AI Agents" Setup Wizard**:
   - Auto-detects installed AI agents and IDEs: **OpenClaw, Hermes, Claude Code, Cursor, Google Antigravity, and Windsurf**.
   - One click injects authenticated MCP configuration into all selected runtimes.

3. **🔔 Native Desktop Integration**:
   - **Windows System Tray**: Runs 24/7 in the background with unread badges.
   - **Windows Native Notifications**: Instant notification popup with sound on incoming emails, OTP verification codes, and tasks.
   - **Embedded Rust Backend**: Starts silently in the background with zero terminal popups.
